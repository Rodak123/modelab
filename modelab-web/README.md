## Setup

### Prerequisites

- Node.js `>=18.17`

### Installation

Clone the repository and install dependencies:

```bash
npm install
```
### Development

To develop the app and packages, run the following command:

```bash
npm run dev
```

Before commiting check and fix **ALL** lint errors:

```bash
npm run lint
```

### Build

To build the app and packages, run the following command:

```bash
npm build
```
